# RemoteRozgar 🇵🇰💼
> **Apna Rozgar, Apne Ghar Se** — 100% Free Remote Job & Internship Aggregator for Pakistan and South Asia.

Built with **Next.js 14**, **Tailwind CSS**, **Lucide Icons**, and **PWA (Progressive Web App)**.  
**Budget:** 0 Rupees (No paid hosting, no paid APIs, no Play Store fees).

---

## 🌟 Key Features

1. **Free Real-Time Remote Jobs:** Powered by the free Jobicy API and curated entries for Pakistani freelancers & students.
2. **USD to PKR Calculator:** Automatically calculates estimated monthly earnings in Pakistani Rupees based on real exchange rates.
3. **1-Click WhatsApp Viral Share:** Formatted with role, company, estimated PKR salary, and app link so users can share to WhatsApp groups.
4. **PWA Mobile Installable:** Users can install the app directly on Android/iOS home screen without paying \$25 to the Play Store.
5. **Non-Intrusive Monetization:**
   - **Google AdSense Ready:** Clean, in-feed native sponsored slots (zero annoying popups).
   - **Affiliate Recommendation:** Certified online course cards (Coursera, Udemy, etc.).
   - **Direct Featured Job Payments:** Local companies pay Rs 1,500/week via **JazzCash / EasyPaisa / Bank Transfer**.
6. **Local Bookmarks:** Save favorite jobs offline via `localStorage` (0 database hosting costs).

## 🚀 How to Run Locally

```bash
# Navigate to project folder
cd remoterozgar

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🌐 How to Deploy to Production for Rs 0 (Free Lifetime Hosting)

1. **Push to GitHub (Free):**
   - Create a free account on [github.com](https://github.com)
   - Create a new repository: `remoterozgar`
   - Push your code to GitHub:
     ```bash
     git init
     git add .
     git commit -m "Initial commit of RemoteRozgar"
     git branch -M main
     git remote add origin https://github.com/YOUR_USERNAME/remoterozgar.git
     git push -u origin main
     ```

2. **Deploy on Vercel (100% Free Forever):**
   - Go to [vercel.com](https://vercel.com) and click **Sign Up** using your GitHub account.
   - Click **Add New Project** -> Select `remoterozgar`.
   - Click **Deploy**.
   - Within 1 minute, your app is live worldwide on a free URL like: `https://remoterozgar.vercel.app`!
